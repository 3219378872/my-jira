# 一站式协作需求基线 v1

版本：2026-09-12。范围来源为用户授权的三阶段计划；正式计划全文见
[ITERATION_PLAN.md](ITERATION_PLAN.md)。根目录 `requirements.md`、`PLAN.md`
是本地临时输入，不纳入 Git。本文、正式计划、实现和验证记录属于版本化交付。

## 产品目标与人物

产品目标是提供一站式高效协作体验：把需求、执行、资源、业务场景和有依据的
改善行动连成可追踪的工作流。平台保留 Admin、Member、Guest 固定角色。
“创建角色”在本次已确认范围内解释为分配现有角色；“项目经理”是业务人物，
按其实际项目角色授权。UML 中的业务角色单独建模，不授予平台权限。

| Epic | 目标 | 人物与价值 |
| --- | --- | --- |
| E1 用户管理与权限 | 让正确的人获得正确的操作和数据访问能力 | 管理员管理访问及自动化授权；成员管理自己的偏好；Guest 仅查看当前授权内容 |
| E2 任务与协作 | 把需求转成可分配、可执行、可协作和可追踪的工作 | 团队成员维护故事、执行任务、文档和业务场景；项目经理维护交付承诺 |
| E3 数据与分析 | 为交付、质量和改进提供可解释依据 | 项目经理观察项目及团队整体指标；团队对照事实复盘与改进 |
